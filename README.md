# FraudShield AI

An AI-powered Food Quality & Adulteration Screening Platform for individual consumers and small food vendors. Developed for BuildSprint 2026.

## Tech Stack
- **Frontend**: Next.js 15, TypeScript, Tailwind CSS
- **Backend**: Java 21, Spring Boot 3, Spring Data JPA, MySQL, Modular AI Layer

## Repository Structure
```
FraudShield-AI/
├── backend/    # Spring Boot application
└── frontend/   # Next.js application
```
